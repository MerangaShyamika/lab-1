## How to run

- Double-click `Practical01.playground` to open it in Xcode. Each exercise is a separate page
  (Exercise01 … Exercise06, FinalChallenge). Select a page and press **Run** (▶) — output appears in the debug console (Shift + Command + Y).
- The `ExerciseXX.swift` and `FinalChallenge.swift` files in this folder are the source-code submission files required by the lab sheet (same code as the playground pages).
